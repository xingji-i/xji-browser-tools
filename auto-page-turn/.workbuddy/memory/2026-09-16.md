## auto-page-turn（浏览器自动翻页扩展）v1.2.0 — 小说站点击式翻页功能

**需求**：访问小说网站时需要手动点"下一页/下一章"按钮，希望增加翻页快捷键和自动翻页功能按钮。

**实现**（改动 `content/content.js`、`popup/popup.html`、`popup/popup.css`、`popup/popup.js`、`background/background.js`、`manifest.json` → 1.2.0）：

1. **下一页链接智能识别 `findNextLink()`**（content.js，启发式评分制）：
   - 候选：`a[rel=next]`、a、button、[role=button]、[onclick]、input[type=button/submit]
   - 评分：rel=next 100 分 / 文本·aria-label·title 匹配 `下一页|下页|下一章|下章|下一节|next|»|›|>>` 90 分 / id·class·name 匹配 `next|nextpage|pb_next|btnnext` 60 分，阈值 30
   - 排除：`上一页|上章|prev|previous|返回|目录|首页` 等反向控件；文本 >30 字符的正文链接（除非属性强匹配）
   - 降权：href 等于当前 URL -40、不可见 -30；加分：位于页面下半部 +10

2. **翻页执行 `doTurnPage(manual)`**：click() 目标元素；SPA 站点不导航时回顶部继续滚动；自动模式写入 sessionStorage 续读标记。

3. **自动翻页模式**：scrollStep 到底部时不再 stopScroll，而是 2s（PAGE_TURN_DELAY）倒计时（指示器显示"已到底 · Ns 后自动翻页"）后自动点下一页；找不到下一页则全部停止并提示"未找到下一页链接"。**跨页面续读**：翻页导航后 content script 销毁，用 `sessionStorage["autoPageTurn.active"]`（同标签页同源导航保留）在新页面 init 时自动恢复滚动+翻页；手动 stopScroll 会清除该标记。用户手动滚动会重置翻页倒计时。

4. **快捷键 Ctrl+→ 翻下一页**：manifest commands 注册 `turn-page`（Chrome 层拦截），content.js 页面级 keydown 兜底；popup 快捷键说明区新增条目。

5. **popup UI**：新增"小说翻页"控制组 = "⏭ 下一页"按钮（点击后 400ms 自动关弹窗）+ "🔁 自动翻页"开关（开启时自动开始滚动）+ 识别状态提示（"已识别下一页"绿 / "未检测到下一页"红，`.link-hint` 样式）；getState 返回 `autoPageTurn` + `nextLinkFound`。

**注意**：用户在本轮之前已自行把 RESUME_DELAY 从 1000ms 改为 500ms（手动滚动恢复延迟），保留未动。

**验证**：`node --check` + JSON.parse 全部通过。功能需浏览器重载扩展实测（小说站翻页识别效果需真实站点验证）。
